## 📊 持仓评估系统详解

### 评估维度（4维度）

| 维度 | 权重 | 评分内容 |
|------|------|----------|
| **技术面** | 40% | 趋势（均线）、形态（支撑压力）、指标（MACD/RSI/KDJ） |
| **资金面** | 30% | 主力资金流向、成交量变化、换手率 |
| **基本面** | 20% | 估值水平（PE/PB）、业绩表现 |
| **市场环境** | 10% | 大盘红绿灯评分 |

### 操作建议规则

#### 1. 继续持有（hold）
- 综合评分 ≥ 60分
- 盈亏在合理范围内
- 无明显风险信号

#### 2. 减仓50%（reduce）
- 综合评分 45-60分（一般）
- 盈利 ≥ 10%（止盈）
- 持仓 ≥ 10天但涨幅 < 5%（效率低）

#### 3. 清仓（sell）
- 综合评分 < 45分（较差）
- 亏损 ≥ 8%（止损）
- 亏损 ≥ 5% 且评分 < 50分（双重风险）

### 风险等级

| 等级 | 条件 |
|------|------|
| **低风险** | 评分 ≥ 70 且盈利 > 0% |
| **中风险** | 评分 ≥ 50 且亏损 < 5% |
| **高风险** | 评分 < 50 或亏损 ≥ 5% |

## 🚦 增强版市场环境红绿灯系统

### 7维度分析（已升级）

| 维度 | 权重 | 说明 |
|------|------|------|
| **大盘趋势** | 25% | 均线排列、价格位置、涨跌幅 |
| **市场情绪** | 20% | 涨跌比、涨停跌停比 |
| **成交量** | 15% | 量能趋势、量价配合 |
| **北向资金** | 10% | 连续流入天数、流入金额 |
| **市场波动率** ⭐ | 10% | 波动率水平（新增） |
| **市场广度** ⭐ | 10% | 上涨股票占比（新增） |
| **板块强度** ⭐ | 10% | 热门板块数量和涨幅（新增） |

### 信号判断

| 信号 | 评分范围 | 操作建议 |
|------|----------|----------|
| 🟢 **绿灯** | ≥ 70分 | 可以积极做多 |
| 🟡 **黄灯** | 40-70分 | 谨慎观望 |
| 🔴 **红灯** | < 40分 | 空仓或轻仓 |

### 单独使用市场环境分析

```python
from src.analysis.market.environment import MarketEnvironment

# 创建分析器
env = MarketEnvironment()

# 分析市场环境
result = env.analyze(days=20)

print(f"交易信号: {result['signal_text']}")
print(f"综合评分: {result['score']}/100")
print(f"详细评分: {result['details']}")
```

## 🔧 高级用法

### 1. 自定义评估权重

编辑 `src/analysis/position_evaluator.py`：

```python
self.weights = {
    'technical': 0.40,      # 技术面 40%
    'capital': 0.30,        # 资金面 30%
    'fundamental': 0.20,    # 基本面 20%
    'environment': 0.10     # 市场环境 10%
}
```

### 2. 自定义市场环境权重

编辑 `src/analysis/market/environment.py`：

```python
self.weights = {
    'trend': 0.25,          # 大盘趋势 25%
    'sentiment': 0.20,      # 市场情绪 20%
    'volume': 0.15,         # 成交量 15%
    'north_money': 0.10,    # 北向资金 10%
    'volatility': 0.10,     # 市场波动率 10%
    'breadth': 0.10,        # 市场广度 10%
    'sector_strength': 0.10 # 板块强度 10%
}
```

### 3. 调整止盈止损阈值

编辑 `src/analysis/position_evaluator.py` 中的 `_generate_action()` 方法：

```python
# 止盈阈值
if profit_pct >= 15:  # 改为您想要的值
    action = 'reduce'
    text = '止盈减仓50%'

# 止损阈值
elif profit_pct <= -8:  # 改为您想要的值
    action = 'sell'
    text = '止损清仓'
```

## ⚠️ 注意事项

### 1. 数据准确性
- 确保 `my_positions.py` 中的数据准确
- `current_price` 需要及时更新（可考虑自动获取）
- `hold_days` 需要手动计算

### 2. API限制
- Tushare API有调用频率限制
- 如果持仓数量多，评估可能需要较长时间
- 建议在盘后进行评估

### 3. 评估时机
- **最佳时机**：每日盘后（15:30-18:00）
- **次佳时机**：盘前（8:30-9:15）
- 避免在盘中频繁评估

### 4. 操作建议
- 系统建议仅供参考，不构成投资建议
- 请结合自己的判断和风险承受能力
- 严格执行止损纪律

## 🆘 常见问题

### Q1: 评估失败怎么办？
**A**: 检查以下几点：
1. Tushare API token是否配置正确
2. 股票代码格式是否正确（如 `600519.SH`）
3. 网络连接是否正常
4. API调用是否超过限制

### Q2: 评估结果不准确？
**A**: 可能原因：
1. 数据延迟（使用的是日线数据）
2. 权重配置不符合您的风格（可自定义）
3. 市场环境特殊（如极端行情）

### Q3: 如何提高评估速度？
**A**:
1. 减少持仓数量
2. 使用更高级的Tushare账户（提高API限制）
3. 缓存历史数据

### Q4: 可以用于盘中实时评估吗？
**A**:
- 当前版本使用日线数据，不适合盘中实时评估
- 如需实时评估，需要接入分时数据（Level-2行情）
