## ✅ 核心优化内容

### 1️⃣ 技术面三维评分（40%权重）

#### 原来：简单评分
- 均线排列
- 价格位置
- 指标状态

#### 现在：三维量化评分
```
技术面 = 趋势分(40%) + 动量分(30%) + 位置分(30%)
```

**趋势分（40分）**：
- 均线多头排列（25分）
  - 完美多头（MA5>MA10>MA20>MA60）：25分
  - 短中期多头（MA5>MA10>MA20）：20分
  - 短期多头（MA5>MA10）：12分
  - 空头排列：5分

- 趋势斜率（15分）- 评估MA20斜率
  - 强势上升（>3%）：15分
  - 温和上升（1-3%）：12分
  - 平稳（0-1%）：8分
  - 下降（<0%）：2-5分

**动量分（30分）**：
- MACD（10分）
  - 金叉且零轴上方：10分
  - 金叉：6-8分
  - 死叉：2分

- RSI（10分）
  - 健康强势区（50-70）：10分
  - 正常区（40-50）：7分
  - 超买区（>80）：3分
  - 超卖区（<30）：4分

- KDJ（10分）
  - 金叉且未超买：10分
  - 金叉：6-8分
  - 超卖：5分

**位置分（30分）**：
- 年内高低点位置（20分）
  - 中间位置（30-70%）：20分
  - 相对低位（20-30%）：18分
  - 年内低位（<20%）：15分
  - 相对高位（70-85%）：15分
  - 年内高位（>85%）：10分

- 距离压力位（10分）
  - 远离压力（>10%）：10分
  - 接近压力（0-2%）：4分
  - 突破压力：10分

### 2️⃣ 资金面深化分析（30%权重）

#### 原来：简单资金流向
- 主力资金
- 成交量
- 换手率

#### 现在：三维深度分析
```
资金面 = 个股资金(50%) + 北向资金(30%) + 成交量(20%)
```

**个股资金流向（50分）**：
- 使用ComprehensiveCapitalScore模块
- 评估主力资金连续流入情况
- 信号提取：
  - ≥80分：✅ 主力资金大幅流入
  - ≥60分：主力资金持续流入
  - ≤40分：⚠️ 主力资金流出

**北向资金（30分）**：
- 使用NorthBoundAnalysis模块
- 评估北向资金持股变化趋势
- 信号提取：
  - ≥75分：✅ 北向资金大幅增持
  - ≥60分：北向资金持续增持
  - ≤40分：⚠️ 北向资金减持

**成交量分析（20分）**：
- 量比分析（12分）
  - 明显放量（>2.0）：12分 + 信号
  - 放量（1.5-2.0）：10分 + 信号
  - 温和放量（1.0-1.5）：8分
  - 正常（0.8-1.0）：6分
  - 缩量（<0.8）：4分 + 信号

- 量价关系（8分）
  - 价涨量增：8分 + ✅ 信号
  - 价涨量平：6分
  - 价跌量缩：7分
  - 价跌量增：3分 + ⚠️ 信号

### 3️⃣ 仓位管理逻辑（新增核心功能）

#### 根据评分自动计算建议仓位

| 综合评分 | 建议仓位 | 说明 |
|---------|---------|------|
| ≥ 80分 | 12-15% | 优质标的，重点配置 |
| 70-79分 | 8-12% | 良好标的，适度配置 |
| 60-69分 | 5-8% | 一般标的，轻仓持有 |
| 50-59分 | 3-5% | 较弱标的，观察仓位 |
| < 50分 | 0-3% | 清仓或极轻仓 |

#### 具体操作建议

**清仓（sell）**：
- 评分 < 45分
- 亏损 ≥ 8%
- 亏损 ≥ 5% 且评分 < 50
- 输出：卖出X股，清仓

**减仓（reduce）**：
- 评分 45-60分
- 盈利 ≥ 15%（止盈）
- 盈利 ≥ 10% 且评分 < 60
- 持仓 ≥ 10天但涨幅 < 5%
- 输出：卖出X股，减仓至Y%

**持有/加仓（hold）**：
- 评分 ≥ 60分
- 当前仓位 < 建议仓位（差异>2%）
- 输出：买入X股，加仓至Y% 或 维持当前仓位

## 📊 评分体系对比

### 原评分体系
```
技术面(40%) = 趋势 + 形态 + 指标
资金面(30%) = 主力资金 + 成交量 + 换手率
基本面(20%) = 估值 + 业绩
市场环境(10%) = 红绿灯评分
```

### 新评分体系（更科学）
```
技术面(40%) = 趋势分(40%) + 动量分(30%) + 位置分(30%)
  ├─ 趋势分: 均线排列(25分) + 趋势斜率(15分)
  ├─ 动量分: MACD(10分) + RSI(10分) + KDJ(10分)
  └─ 位置分: 年内位置(20分) + 压力位(10分)

资金面(30%) = 个股资金(50%) + 北向资金(30%) + 成交量(20%)
  ├─ 个股资金: 主力资金流向分析
  ├─ 北向资金: 持股变化趋势
  └─ 成交量: 量比(12分) + 量价关系(8分)

基本面(20%) = 估值水平 + 业绩表现
市场环境(10%) = 7维度红绿灯评分
```

## 🔧 自定义配置

### 修改仓位规则
编辑 `position_evaluator.py`：
```python
self.position_rules = {
    80: (12, 15),   # 评分≥80: 12-15%
    70: (8, 12),    # 评分70-79: 8-12%
    60: (5, 8),     # 评分60-69: 5-8%
    50: (3, 5),     # 评分50-59: 3-5%
    0: (0, 3)       # 评分<50: 0-3%
}
```

### 修改评分权重
```python
# 技术面内部权重
trend_score * 0.4 + momentum_score * 0.3 + position_score * 0.3

# 资金面内部权重
individual_score * 0.5 + north_score * 0.3 + volume_score * 0.2
```
