## 快速开始

### 1. 环境检查


### 功能2：ATR仓位管理（已优化）

**功能**：根据股票波动性动态计算仓位，控制总风险

**运行命令**：
```bash
python tests/test_atr_improvements.py
```

**核心改进**：
- ✅ ATR周期优化：7日ATR（70%）+ 14日ATR（30%）
- ✅ 总风险暴露检查：上限16%

**输出示例**：
```
600519.SH:
  建议仓位：500股
  建议金额：925,000.00元 (9.3%)
  止损价：1,468.50元

当前总风险暴露: 6.28%
买入后总风险: 7.62%
风险上限: 16.00%
✅ 可以买入
```

**使用方法**：
```python
from src.trading.atr_position_sizer import ATRPositionSizer

# 初始化
sizer = ATRPositionSizer(
    total_capital=1000000,      # 总资金100万
    risk_percent=4,             # 单只股票风险4%
    max_total_risk=16           # 总风险上限16%
)

# 计算单只股票仓位
position_size, position_value, stop_loss = sizer.calculate_position_size(
    ts_code='600519.SH',
    score=85
)

# 计算仓位（带总风险检查）
current_positions = {
    '000858.SZ': {'quantity': 2000, 'cost_price': 100}
}
position_size, position_value, stop_loss, risk_info = sizer.calculate_position_size_with_risk_check(
    ts_code='600519.SH',
    score=85,
    current_positions=current_positions
)
```

### 功能3：动态风控管理

**功能**：5层风控机制，自动生成止损止盈建议

**运行命令**：
```bash
python tests/test_dynamic_risk.py
```

**5层风控**：
1. ATR动态止损
2. 评分动态止损
3. 时间止损（最大持仓5天）
4. 市场环境止损
5. 组合风控

**输出示例**：
```
场景1（持仓2天，盈利10%）：
  建议：减仓50%（快速止盈）
  理由：持仓2天盈利10%，触发快速止盈规则

场景2（持仓4天，亏损5%）：
  建议：清仓
  理由：亏损触及止损线
```

**使用方法**：
```python
from src.risk.dynamic_risk_manager import DynamicRiskManager

risk_mgr = DynamicRiskManager(
    max_hold_days=5,
    quick_profit_days=2,
    quick_profit_target=8
)

action = risk_mgr.check_position(
    ts_code='600519.SH',
    cost_price=1800,
    current_price=1980,
    hold_days=2,
    score=85
)
```

## 配置调整

### 调整因子权重

编辑 `config/ultra_short_term_config.py`：

```python
'factor_weights': {
    'technical_score': 35,      # 技术面权重（可调整）
    'north_bound_score': 20,    # 北向资金权重（可调整）
    'main_capital_flow': 10,    # 主力资金权重（可调整）
    'sector_strength': 15,      # 板块强度权重（可调整）
    'market_cap': 5,            # 市值权重（可调整）
    'roe': 3,                   # ROE权重（可调整）
    'pe_percentile': 2,         # PE百分位权重（可调整）
}
```

**注意**：所有权重之和必须等于100%

---

### 调整风险参数

编辑 `config/ultra_short_term_config.py`：

```python
'position': {
    'risk_percent': 4,          # 单只股票风险暴露（2-6%）
    'max_single_position': 15,  # 单只最大仓位（5-20%）
    'max_total_position': 85,   # 总仓位上限（50-95%）
    'max_total_risk': 16,       # 总风险上限（12-20%）
}
```

---

### 调整调仓频率

编辑 `config/ultra_short_term_config.py`：

```python
'selection': {
    'rebalance_days': 3,        # 调仓频率（2-10天）
}
```

## 常见问题

### Q1: 如何查看当前配置？

```bash
python -c "from config.ultra_short_term_config import ULTRA_SHORT_TERM_CONFIG; import json; print(json.dumps(ULTRA_SHORT_TERM_CONFIG, indent=2, ensure_ascii=False))"
```

---

### Q2: 如何修改总资金？

在运行测试脚本时修改：
```python
sizer = ATRPositionSizer(
    total_capital=1000000,  # 修改这里
    risk_percent=4
)
```

或者在配置文件中添加：
```python
'capital': {
    'total': 1000000,  # 总资金
}
```

---

### Q3: 如何查看历史测试结果？

测试输出会保存在终端，建议重定向到文件：
```bash
python tests/test_enhanced_multi_factor.py > logs/test_$(date +%Y%m%d).log 2>&1
```

---

### Q4: 如何备份配置？

```bash
# 备份配置文件
copy "config\ultra_short_term_config.py" "config\ultra_short_term_config_backup_$(date +%Y%m%d).py"
```

---

### Q5: 如何恢复默认配置？

查看 `config/ultra_short_term_config.py` 中的默认值，或参考计划文件：
```bash
type "<计划文档路径>"
```

---

### Q6: 测试脚本运行失败怎么办？

**常见错误**：

1. **Tushare Token未配置**
   ```
   错误：TushareAPI初始化失败
   解决：编辑 config/tushare_config.py，填入你的token
   ```

2. **数据获取失败**
   ```
   错误：无法获取股票数据
   解决：检查网络连接，或稍后重试
   ```

3. **模块导入失败**
   ```
   错误：ModuleNotFoundError
   解决：检查是否在项目根目录运行
   ```

---

### Q7: 如何查看详细日志？

编辑 `src/utils/logger.py`，调整日志级别：
```python
log.setLevel(logging.DEBUG)  # 显示详细日志
```
