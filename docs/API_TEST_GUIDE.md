## 常见问题

### 问题1：服务器无法启动

**错误**：`Address already in use`

**解决**：
```bash
# 查找占用5000端口的进程
netstat -ano | findstr :5000

# 结束进程（替换<PID>为实际进程ID）
taskkill /PID <PID> /F
```

### 问题2：API返回"请先下载财务报表"

**原因**：测试公司的财务报表还未下载

**解决**：
1. 访问 http://localhost:5000
2. 搜索并选择公司
3. 点击"下载财务报表"
4. 等待下载完成后再测试

### 问题3：API返回"趋势分析失败"

**可能原因**：
1. 财报数据不完整
2. 数据格式错误
3. 计算过程中出现异常

**解决**：
1. 查看服务器控制台的错误日志
2. 检查 `data/financial_reports/<ts_code>/` 目录下的数据文件
3. 重新下载财务报表
